两种用法 · 左右都能用

按住直达，双击看着选。

左右两个 ⌘ 各自决定怎么用：按住 + 字母、双击弹面板，或者两样都开。默认是右 ⌘ 按住、左 ⌘ 双击；想用左手，把左 ⌘ 的“按住”也打开就行。

按住 ⌘ + 字母

右⌘ 或 左⌘ 按住 + 字母

  • 指定了 app 的字母：没开就启动，开着就切过去，已经在最前就隐藏；再按一次切回来。
  • 右 ⌘ 没指定的字母：在名字以这个字母开头、正在运行的 app 之间轮换，比如按 W 在微信和天气之间切。
  • 左 ⌘ 只接管指定过的字母：⌘C、⌘V、⌘W 这些照常工作。设置里如果左 ⌘ 占了常用快捷键，会直接提示是哪几个。
  • 同时按着 ⇧、⌥、⌃ 的组合一律照常交给当前 app。两个 ⌘ 同时按住时以右 ⌘ 为准。

双击 ⌘，再按字母

⌘ ⌘ → 字母

  • 快速按两下 ⌘（左右都可以开），屏幕中间弹出这一边的字母面板，按字母就切换。
  • 面板不会抢当前窗口的焦点，按 Esc 或 4 秒不按键会自动关闭。
  • 按 ⌘C 之类的组合、按住不放、两下之间点了鼠标，或者左右 ⌘ 各按一下，都不会算作双击。

设置

一张字母表，几个开关。

点菜单栏的 ⌘ 图标 → 设置。键盘操作：⌘1/⌘2 切换右 ⌘ / 左 ⌘，⌘N 添加，⌫ 移除，↩ 换 app，⌘W 关闭。

  • 左右 ⌘ 各两个开关：“按住 + 字母”和“双击弹面板”，可以只开一个，也可以都开。
  • 按下的 app 已在最前时隐藏它：再按一次切回来，和 rcmd 的习惯相同。
  • 未指定的字母轮换运行中的 app：关掉的话，只有指定过的字母才会响应。
  • 左 ⌘ 使用与右 ⌘ 相同的字母：默认打开，只维护一张表；关掉可以给左边单独设。
  • 登录时打开：开机自动运行，常驻菜单栏。

安装

三步，第二步要授权一次。

需要 macOS 14 或更新，Apple Silicon（M 系列）。

  1. 1

    下载并拖进“应用程序”

    打开下载的 DMG，把 Initials 拖到 Applications，然后从“应用程序”打开它。安装包已经过 Apple 公证，可以直接打开。

  2. 2

    允许“辅助功能”

    第一次打开会显示设置窗口。点 打开辅助功能设置…，在“系统设置 › 隐私与安全性 › 辅助功能”里打开 Initials 的开关。回到设置窗口，顶部变成 ✓ 已授权辅助功能，正在工作 就好了，不用重启。

    为什么需要它：Initials 要接到 ⌘ + 字母，并且不让这个按键再传给当前 app。它只看 ⌘ 和紧跟的字母，不记录、不保存你打的字。

  3. 3

    给字母指定 app

    点 添加… 选 app 并挑字母。已经在用 Hammerspoon rcmd 的，点 从 Hammerspoon 导入，确认好用之后再点 关闭 Hammerspoon rcmd，免得两边同时处理同一个键。

命令行

和设置窗口改的是同一份配置。

安装后命令在 /Applications/Initials.app/Contents/Resources/bin/initials，可以链接到自己的 PATH 里。改完即时生效。

initials list                      # 两边的字母表
initials set m Music               # 右 ⌘ + M → 音乐（名字、bundle id 或 .app 路径都行）
initials set w WeChat --side left  # 只给左 ⌘ 设（先 initials share off）
initials unset m
initials import                    # 导入 ~/.hammerspoon/keymaps.lua 的 right_command
initials status                    # 是否在运行、是否已授权、是否在拦截
initials hold on --side left       # 左 ⌘ 也按住 + 字母直达（只接管指定过的字母）
initials tap on --side right       # 右 ⌘ 也能双击弹面板
initials tap off --side left       # 关掉双击左 ⌘

退出码：0 成功，1 没找到，2 用法错误，3 Initials 没在运行（status）。配置文件：~/Library/Application Support/cyou.tianli.initials/config.json。

遇到问题

对照情况，按下一步做。

按右 ⌘ + 字母没反应

先看菜单栏的 ⌘ 图标：变灰说明还没授权或已暂停。打开设置，顶部如果提示需要授权，点“打开辅助功能设置…”打开开关。也可以在终端运行 initials status，看 intercepting 是不是 yes。

装了新版本以后又不灵了

macOS 有时会让旧的授权失效。到“辅助功能”列表里把 Initials 关掉再打开；还不行就用“−”删掉，再重新添加。

双击左 ⌘ 太容易误触，或者总是触发不了

两下之间和每一下的时长默认都是 0.3 秒以内。不需要这个功能，可以在设置的“左 ⌘”页取消“快速按两下左 ⌘”，或者运行 initials tap off --side left。

和 Hammerspoon / rcmd 同时装会冲突吗

两个工具可能同时处理同一个键。确认 Initials 好用后，在设置里点“关闭 Hammerspoon rcmd”，只留一个处理。以后想恢复，点同一个按钮。

用中文输入法时字母对不上

Initials 按物理键码映射字母，不随当前输入法变化。非 QWERTY 键盘布局上的字母可能与键帽不同。

想让某个右 ⌘ + 字母留给当前 app 用

右 ⌘ 同时按 ⇧、⌥ 或 ⌃ 时不会被拦截。要完全停用右 ⌘ 这一边，运行 initials disable right。

打开左 ⌘ 按住后，⌘C、⌘V 会不会失灵

左 ⌘ 按住只接管字母表里指定了 app 的字母，其余快捷键照常。默认左 ⌘ 和右 ⌘ 共用一张表，如果表里有 C、V、W 之类的字母，设置窗和 initials list 都会标出被占用的快捷键；这时关掉“使用与右 ⌘ 相同的字母”，给左边单独设几个不常用的字母即可。

支持 Intel Mac、Windows 或 Linux 吗

当前下载包只支持 Apple Silicon 和 macOS 14 或更新版本，没有 Intel、Windows 或 Linux 安装包。
